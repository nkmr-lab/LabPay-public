LabPay プライバシーポリシー

最終更新: 2026年6月3日

1. はじめに

LabPay (以下「本アプリ」) は、明治大学 中村研究室 (nkmr-lab) のメンバーが 研究室内で利用する非営利の内部ツールです。本ポリシーは、本アプリが収集・ 利用するデータと、利用者の権利について説明します。本アプリは 研究室のメンバー以外には公開されていません。

3. 収集する情報

3.1 Google ログイン時に取得する情報

本アプリは Google アカウントによる認証を採用しています。下記のスコープでのみ情報を取得します。

  • openid / email / profile — メールアドレス、表示名、プロフィール画像

3.2 Google Calendar 連携 (任意)

利用者が「設定」 画面から明示的に連携を許可した場合に限り、https://www.googleapis.com/auth/calendar.readonly スコープを取得します。連携は任意で、連携しなくても本アプリは利用できます。

3.3 利用者がアプリ内で入力する情報

  • 表示名、アバター画像 (任意)、Scrapbox ハンドル (任意)
  • 研究室内 Wi-Fi に接続する端末の MAC アドレス (在室判定のため、利用者本人が登録)
  • 商品の出品情報、購入・送金・タスクなどの活動履歴
  • バグ報告・機能要望のテキスト

3.4 自動的に記録される情報

  • 本アプリへの API リクエスト履歴 (アクセス時刻、メソッド、パス、ステータス、IP アドレス、User-Agent)
  • 研究室内 Wi-Fi スキャナによる端末検知記録 (登録 MAC のみ、研究室在室判定のため)

4. Google API データの取り扱い

本アプリによる Google ユーザーデータの利用は、Google API Services User Data Policy (Limited Use 要件を含む) に準拠します。

4.1 calendar.readonly スコープの利用範囲

連携した Google Calendar データを下記の目的にのみ利用します。

  • 利用者本人のホーム画面上に「今日・明日の予定」 を表示する
  • 利用者が選択した「表示対象カレンダー」のイベント一覧を取得する
  • イベントに含まれる Zoom / Google Meet URL を表示し、ワンタップで会議に参加できるようにする

4.2 やらないこと

  • 取得した Calendar データを 他のユーザーに表示しない (本人のホーム画面でのみ表示)
  • 取得した Calendar データを 第三者に提供・販売しない
  • 取得した Calendar データを 広告や AI モデルの訓練に利用しない
  • イベント本文・参加者情報を サーバー側で永続保存しない (リクエスト時に Google から取得して即時表示)
  • カレンダーの 書き込み・編集・削除はしない (readonly スコープのみ)

4.3 トークンの保存

Google から発行された access_token / refresh_token は、本アプリのデータベースに 利用者単位で暗号化された通信経路で保存されます。これらは本人の Calendar API 呼び出しにのみ使用されます。利用者は設定画面から いつでも連携を解除 できます。

5. データの利用目的

  • 研究室内のポイント (LabPay) 経済の運営 (出品・購入・送金・タスク報酬の記録)
  • 研究室における在室状況の可視化 (本人および同僚)
  • 研究室内で募集される予定 (お昼ご飯・スキー旅行など) の調整
  • 請求 (集金)・割り勘の管理
  • 利用者本人のスケジュール表示 (Google Calendar 連携時)

6. データの第三者提供

本アプリは収集したデータを第三者に提供しません。例外:

  • 法令に基づく要請がある場合
  • 利用者本人が表示を許可した範囲のデータ (例: 出品物の出品者名は研究室内の他メンバーに表示されます)
  • 本アプリの運用に必要なインフラ事業者 (本アプリは自前サーバーで運用しており、外部 SaaS 上にユーザーデータは置いていません)

7. データの保管期間

  • 利用者が研究室を卒業・退室した場合、本人の申し出により 原則 30 日以内に個人を特定する情報を削除します
  • Google Calendar 連携トークンは、利用者が「連携を解除」 を押した時点で即座に DB から削除されます
  • API リクエストログは運用上必要な範囲 (90 日以内) で保管します

8. データ削除・連携解除の方法

  1. Google Calendar 連携の解除: 本アプリ内 「設定」 → 「Google Calendar 連携」 → 「連携を解除」 をタップ
  2. Google アカウント側からの取り消し: Google アカウント > サードパーティ アプリとサービス から LabPay を選んで「アクセス権を取り消す」
  3. アカウント削除の依頼: 上記の連絡先メールに「LabPay アカウント削除希望」 と送ってください

9. セキュリティ

  • 本アプリは HTTPS (TLS) でのみ通信します
  • セッションは HttpOnly + SameSite=Lax の Cookie で管理します
  • 状態変更 API には X-Requested-With ヘッダーによる CSRF 対策を行っています
  • パスワードは保存しません (Google OAuth のみで認証)

10. 本ポリシーの改定

本ポリシーは、機能追加または法令の改定に応じて改定されることがあります。 重要な変更は研究室メンバーに事前に通知します。本ページ冒頭の 「最終更新」 日が改定日となります。
